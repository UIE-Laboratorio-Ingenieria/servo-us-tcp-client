# Contributing

Actualmente el mantenimiento de este proyecto es responsabilidad del Laboratorio de Ingeniería de la UIE.

Los cambios se incorporan directamente mediante commits realizados por los responsables del proyecto.

Si detecta errores, problemas de documentación o posibles mejoras, puede comunicarlos mediante la creación de una incidencia (Issue) en GitHub o poniéndose en contacto con el equipo docente.
